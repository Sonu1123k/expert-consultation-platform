# 🧑‍⚕️ Expert Consultation Platform

A modern web application where users can book 1-on-1 consultations with experts. Includes video calls, chat, and payments - all in one place.

![Next.js](https://img.shields.io/badge/Next.js-14-black)
![TypeScript](https://img.shields.io/badge/TypeScript-5-blue)
![Clerk](https://img.shields.io/badge/Auth-Clerk-purple)
![Vercel](https://img.shields.io/badge/Deploy-Vercel-black)

## ✨ Key Features

### For Users
- **Secure Authentication** - Login with Google, Email, Phone via Clerk
- **Expert Search** - Filter by Category, Rating, and Price
- **Booking System** - Select time slots from calendar
- **Dashboard** - View upcoming and past consultations
- **Fully Responsive** - Works on Mobile, Tablet, and Desktop

### For Experts 
- **Expert Dashboard** - Manage bookings and availability
- **Profile Setup** - Add bio, skills, and pricing
- **Availability Management** - Toggle slots on/off
